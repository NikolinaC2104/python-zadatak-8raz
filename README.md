# Python zadatak za 8. razred – Rezultati školskog natjecanja

## Opis projekta

Ovaj projekt sadrži zadatak iz programiranja u programskom jeziku Python, namijenjen učenicima 8. razreda osnovne škole.

Zadatak je izrađen u Jupyter Notebooku kako bi učenici mogli postupno pratiti objašnjenja, izvršavati pojedine dijelove koda i odmah vidjeti rezultate rada programa.

Tema zadatka je obrada rezultata školskog natjecanja.

## Cilj zadatka

Cilj zadatka je ponoviti i primijeniti osnovne programske naredbe i strukture te algoritam sortiranja.

Učenici u zadatku koriste:

- `print()`
- `input()`

- `str()`
- varijable
- liste

- petlju `for`
- `range()`

- algoritam sortiranja

## Zadatak

Na školskom natjecanju iz informatike sudjelovalo je pet učenika.

Potrebno je napisati program koji će:

1. omogućiti unos broja bodova za pet učenika
2. spremiti unesene bodove u listu
3. sortirati bodove od najvećeg prema najmanjem
4. ispisati sortirane rezultate
5. ispisati najbolji ostvareni rezultat

Za sortiranje nije dopušteno koristiti ugrađene Python mogućnosti `sort()` ili `sorted()`.

Potrebno je primijeniti algoritam sortiranja uspoređivanjem i zamjenom susjednih elemenata.
